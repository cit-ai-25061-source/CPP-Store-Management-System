# Store Management System - C++ Project

## What is this project?
This is my individual project for the C++ programming course. I built a simple system to help manage a store's items. It's a console app where you can add products to the system, see everything in the inventory, and search for a specific item using its ID.

## What can it do?
- **Add Products:** You can put in the product ID, name, how many you have (quantity), and the price.
- **View Inventory:** It shows all the products you've added in a nice, organized list.
- **Find Items:** If you have many items, you can just type the ID to find a specific product quickly.
- **Data Storage:** It uses a `struct` array to keep track of all the items while the program is running.

## Programming Concepts I Used
In this project, I tried to apply what we learned in class:
- **Structs:** I created a `struct` called `Product` to keep all the info (like name and price) together.
- **Arrays:** I used an array to store all the product objects in one place.
- **Functions:** I split the code into different functions like `addProduct()` and `displayProducts()` to make it cleaner and easier to read.
- **Loops & Logic:** I used a `while` loop for the main menu and `if/else` for the search and input logic.

## How to use it
1. You need a C++ compiler or an IDE like VS Code or CodeBlocks.
2. Open the `main.cpp` file.
3. Compile and run the code.
4. Follow the menu on the screen to manage your store!
